# Installation de la correction – 26 octobre 2026

1. Décompresser le ZIP de mise à jour.
2. Aller à la racine du dépôt GitHub `guide-local-ibis-montbeliard`, branche `main`.
3. Via **Add file → Upload files**, envoyer **tous les fichiers et dossiers décompressés**, notamment `data.js`, `index.html`, `tv.html`, `sources.html`, `scripts/` et `.github/`.
4. Cliquer sur **Commit changes**.
5. Contrôler **Actions** : la dernière publication Pages doit être réussie. Actualiser le site avec `Ctrl + F5`.
6. Tester les boutons « Site officiel » pour **Le Châtel**, **Chocolaterie Vergne**, **Le Café Central**, **Billiotte**, **Gare TGV** et **Littéra**.

**Aucune photo ne doit être réimportée pour cette mise à jour.**

## Vérification hebdomadaire

Dans GitHub, l’onglet **Actions** affichera une tâche « Vérification des liens du guide ». Tu peux la lancer manuellement avec **Run workflow** ou consulter les résultats hebdomadaires. GitHub peut nécessiter d’autoriser les workflows sur le dépôt. Le CSV téléchargeable est un diagnostic, pas une preuve d’ouverture commerciale ou d’exactitude des horaires.

Si GitHub n'accepte pas les fichiers/dossiers commençant par un point lors du glisser-déposer, le site fonctionne même sans `.github/`; seul le contrôle automatique ne sera pas installé. Le guide continuera à utiliser les URL déjà revues.
