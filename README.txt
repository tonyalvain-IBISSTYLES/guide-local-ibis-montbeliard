GUIDE LOCAL INTERACTIF — IBIS STYLES MONTBÉLIARD CENTRE VELOTTE

CONTENU
- index.html : site web bilingue FR/EN, responsive mobile, recherche, catégories, liens d'appel et itinéraires à pied Google Maps.

TESTER LE SITE
1. Décompressez le dossier ZIP.
2. Ouvrez index.html dans un navigateur (Chrome, Edge, Firefox).

PUBLIER GRATUITEMENT AVEC GITHUB PAGES
1. Créez/connectez-vous à un compte sur https://github.com
2. Créez un nouveau dépôt public, par exemple guide-local-ibis-montbeliard.
3. Importez index.html et README.txt à la racine du dépôt.
4. Ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez Deploy from a branch, branche main, dossier /(root), puis Save.
6. Attendez la publication : GitHub affichera une URL publique. Testez-la sur téléphone avant de créer le QR code.

À VÉRIFIER AVANT PUBLICATION
- Confirmer les noms, adresses et horaires des restaurants, ainsi que les durées à pied.
- Taxi Far : numéro et disponibilité 24h/24 fournis par l'hôtel, à confirmer.
- Laverie Speed Queen : horaires affichés en ligne, à vérifier avant publication définitive.
- Pharmacie : horaires susceptibles de changer ; pour la pharmacie de garde, consulter le service officiel / 3237.
- Ce fichier ne contient pas encore le QR code, car celui-ci doit pointer vers l'URL publique définitive.
