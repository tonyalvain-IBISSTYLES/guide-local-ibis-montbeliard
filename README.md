Aucune photo authentique d'établissement disponible avec droits de réutilisation confirmés lors de cette livraison. Les emplacements photo sont du texte, pas des photographies simulées.
Pour chaque ajout, consigner : établissement, fichier, auteur, URL source, licence ou accord écrit, date, texte alternatif dans les quatre langues. Ne jamais réutiliser la photo d'un lieu pour un autre.
