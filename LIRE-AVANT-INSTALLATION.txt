INSTALLATION
1. Decompressez le ZIP.
2. Ouvrez https://github.com/tonyalvain-ibisstyles/guide-local-ibis-montbeliard/upload/main
3. Importez index.html et tv.html A LA RACINE du depot (pas le ZIP).
4. Validez avec Commit changes.
5. Attendez la publication GitHub Pages, puis revenez dans Cloudflare Web Analytics et cliquez sur Next.
6. Ouvrez le guide depuis un navigateur sans blocage de suivi. Les statistiques ne sont pas retroactives.

ATTENTION : si les fichiers index.html ou tv.html ont ete modifies directement sur GitHub depuis la mise a jour du logo, ne les remplacez pas sans fusionner vos nouvelles modifications.
