Diagnostic des photos du guide

Cette page vérifie les fichiers d’images hébergés sur GitHub et les photos externes.

Ce que vous devez savoir

Si le site affiche les photos mais que certaines lignes « fichiers GitHub » indiquent Absent, c’est le fichier photo-cache.js qui prend le relais : le dossier images/ a probablement été oublié lors de l’import.

Les photos Wikimedia Commons peuvent ne pas se charger pour des raisons externes. Le guide utilise alors un visuel de secours.
